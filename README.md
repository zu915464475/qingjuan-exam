# 青卷在线考试

教师维护题库，学生注册后随机组卷、保存答卷并由服务端评分。

## 部署

GitHub Pages 发布来源选择 main 分支的 /docs 目录。
docs 是已构建的前端；src 是 React 源码。执行 npm install 与 npm run build 可重新构建，将 dist 内容更新到 docs。

Supabase Edge Function exam 提供 API。函数内部验证自有会话和教师权限，所以平台 JWT 校验关闭；不要删除业务身份检查。数据库位于未公开的 qingjuan schema，启用 RLS 且不向 anon/authenticated 授权，浏览器无法直接读取题库答案。服务端使用平台内置 SUPABASE_DB_URL，仓库不包含数据库密码。

schema.sql 只供空数据库初始化参考，已迁移项目不要重复执行。真实题库、账号密码摘要、测试凭证不在仓库中。

登录沿用迁移前的用户名及密码。学生只能注册学生账号。教师首次初始化接口已关闭。
会话保存在当前浏览器标签页的 sessionStorage，关闭标签页后需重新登录。

## 验证范围

已验证注册登录、随机抽题、保存交卷、服务端评分、权限隔离、注销、20个并发读取和手机布局。
尚不代表100人同时考试的负载保证；中国大陆运营商访问需在实际考试网络验收。
